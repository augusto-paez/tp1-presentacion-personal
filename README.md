# TP1 - Presentación Personal

## Qué es
Página de presentación personal estática desarrollada con React y Tailwind CSS v4 como primera entrega del Sprint 1 de la Diplomatura Full Stack. Estructurada en componentes reutilizables con props, renderizado condicional y manejo de eventos.

## Cómo correrlo

1. Clonar el repositorio:
   ```bash
   git clone https://github.com/augusto-paez/tp1-presentacion-personal.git
   cd tp1-presentacion-personal

2. Instalar dependencias:
   ```bash
   pnpm install

   ```
   
3. Ejecutar en modo desarrollo:
   ```bash
   pnpm dev
   ```
## Uso de IA
Utilicé IA para orientarme en la estructura inicial del proyecto y en las decisiones
de componentización. Las sugerencias de código las revisé, modifiqué y simplifiqué
antes de incluirlas, priorizando que cada línea sea entendible para mí.

## Lo que me costó
Entender por qué los handlers de eventos deben declararse fuera del JSX y no inline. También acostumbrarme a pensar en términos de componentes y props en lugar de escribir todo junto en un solo archivo.
